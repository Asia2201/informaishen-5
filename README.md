# Інтерактивний навчальний вебзастосунок з інформатики (5 клас НУШ)
Тема: «Інформаційні процеси. Файли та папки»

## Інструкція для публікації на GitHub Pages:
1. Завантажте файл `index.html` у ваш репозиторій на GitHub.
2. Перейдіть у розділ **Settings** -> **Pages**.
3. Увімкніть публікацію з гілки `main` (root).
