# Інтерактивний вебзастосунок «Інформаційні процеси. Файли та папки» (5 клас НУШ)

Навчальний вебзастосунок розроблений для проведення практичних робіт з інформатики у 5 класі НУШ.

## 🚀 Інструкція з розміщення на GitHub Pages

1. **Розпакування:**
   Розпакуйте отриманий ZIP-архів у зручну папку на комп'ютері.

2. **Створення репозиторію на GitHub:**
   - Увійдіть до вашого облікового запису на [GitHub](https://github.com).
   - Натисніть кнопку **New repository** (Новий репозиторій).
   - Вкажіть назву репозиторію, наприклад: `informational-processes-5class`.
   - Виберіть статус **Public** (Публічний).
   - Натисніть **Create repository**.

3. **Завантаження файлів:**
   - На сторінці нового репозиторію натисніть **uploading an existing file**.
   - Перетягніть усі файли та папки з розпакованого архіву (`index.html`, `css/`, `js/`, `README.md`, `.nojekyll`).
   - Натисніть **Commit changes**.

4. **Увімкнення GitHub Pages:**
   - Перейдіть у вкладку **Settings** у верхньому меню репозиторію.
   - У лівому боковому меню виберіть розділ **Pages**.
   - У секції *Build and deployment* переконайтеся, що джерелом обрано `Deploy from a branch`.
   - Виберіть гілку `main` (або `master`) та папку `/ (root)`.
   - Натисніть **Save**.

5. **Отримання та оновлення посилання:**
   - За 1-2 хвилини у верхній частині сторінки з'явиться готове посилання на застосунок вида: `https://<ваш-нікнейм>.github.io/informational-processes-5class/`.
   - Для оновлення даних просто редагуйте або завантажуйте нові файли через інтерфейс GitHub чи Git.
