# Інтерактивний вебзастосунок «Інформаційні процеси. Файли та папки» (5 клас НУШ)

Повноцінний автономний вебзастосунок для проведення інтерактивної практичної роботи з інформатики у 5 класі НУШ.

## 🚀 Як завантажити на GitHub Pages:

1. **Розпакувати файл** `informational_processes_5class_fixed.zip`.
2. **Створити репозиторій** на [GitHub](https://github.com) (наприклад, `informational-processes-5class`).
3. **Завантажити всі файли** (`index.html`, `css/`, `js/`, `.nojekyll`, `README.md`) у створений репозиторій через кнопку **Upload files**.
4. **Увімкнути GitHub Pages** у розділі `Settings` -> `Pages` -> обрати гілку `main` / `/ (root)` та натиснути **Save**.
5. Отримати готове посилання для учнів!
